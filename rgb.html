Як записують кольори в CSS

Колір на екрані можна задати трьома значеннями: червоним, зеленим і синім. Для кожного значення можна взяти число від 0 до 255.

Запис RGB

rgb(червоний, зелений, синій)

rgb(255, 0, 0)
rgb(0, 255, 0)
rgb(0, 0, 255)
rgb(128, 128, 128)

Шістнадцятковий запис

У CSS колір також можна записати як #RRGGBB. Після знака # ідуть пари цифр для червоного, зеленого та синього каналів. У шістнадцятковій системі використовують цифри 0–9 і літери A–F; кожна пара задає число від 00 до FF (від 0 до 255).

  • #FF0000 — червоний
  • #00FF00 — зелений
  • #0000FF — синій
  • #000000 — чорний, #FFFFFF — білий

Скорочений запис на кшталт #F00 можливий, коли кожна пара складається з однакових символів: #F00 означає #FF0000.
