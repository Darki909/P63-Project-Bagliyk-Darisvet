Форми HTML

Форми потрібні для введення даних. У таблиці показані різні елементи, які можна додати до форми.

Елемент Приклад Призначення
Текст Короткий текстовий рядок
Пароль Приховує введені символи
Електронна пошта Перевіряє формат адреси
Число Числове значення з обмеженнями
Телефон Введення номера телефону
Дата Вибір календарної дати
Час Вибір часу
Колір Вибір кольору
Діапазон Вибір значення повзунком
Прапорець Незалежний вибір одного пункту
Перемикачі Вибір одного пункту групи
Файл Вибір файлу на пристрої
Список Вибір значення зі списку
Багаторядковий текст Введення довшого тексту
